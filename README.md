# Python for Data Science — Learning Lab

A collection of hands-on learning material for **Python, NumPy, Pandas, Matplotlib and scikit-learn**. This repository documents programming practice and data-science fundamentals rather than a production machine-learning application.

## Repository guide

| Directory or file | Subject |
| --- | --- |
| `Python Basics/` | Core Python programming |
| `Numpy/` | Array manipulation |
| `Pandas/` | Tabular data |
| `Matplotlib/` | Data visualization |
| `Scikit/` | Machine-learning examples |
| `DataSample/` | Practice datasets |
| `Github/` | Git and GitHub notes |
| `python.ipynb` | Notebook exercises |
| `index.html` | Browser-based learning index |

## Get started

```bash
git clone https://github.com/TheRitikYadav/ds26.git
cd ds26
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas matplotlib scikit-learn jupyter
jupyter notebook
```

Individual lessons may need additional packages or files. There is no single model-training command for the entire repository.

## Covered concepts

- Python types, collections, iteration and functions
- Vectorized array operations and numerical computing
- Data cleaning, filtering, joining and aggregation
- Plotting and exploratory data analysis
- Basic supervised-learning workflows and evaluation

## Project status

**Educational work in progress.** Files were collected as practice material and are not presented as a tested software package.

## Why this repo exists

To keep an organized, reproducible record of progressing from Python fundamentals to data analysis and applied machine learning.
